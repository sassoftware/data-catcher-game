# Data Catcher

## Overview

Data Catcher is a two-person, arcade-style game designed to illustrate the complexity of collecting the ever-increasing amount of data in a digital world.

### Prerequisites

This project requires Node. It was made with Node v22.21.1.

## Installation

To install project dependencies and set up for running the project, go to the root directory and run:

```
npm install
```

### Getting Started

To run the application as a developer, run the following command:

```
npm run dev
```

### Running

#### Build

To make a production build, run the following command:

```
npm run build
```

#### Start

To run in production mode, run the following command after completing a successful build:

```
npm run start
```
